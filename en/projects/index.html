InvestLink MCP — MCP Server with RAG

MCP (Model Context Protocol) server with six tools: hybrid search with pgvector and EmbeddingGemma running on CPU over 160 documentation sections written from the code, and read-only queries on the market database, with PostgreSQL itself as the security barrier. Retrieval was measured question by question until it hit 29 out of 29. In the public demo, a free Gemini picks the tools and a panel shows every call live — and documenting the code uncovered five InvestLink bugs, fixed with tests.
