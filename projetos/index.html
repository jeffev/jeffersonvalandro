InvestLink MCP — servidor MCP com RAG

Servidor MCP (Model Context Protocol) com seis ferramentas: busca híbrida com pgvector e EmbeddingGemma rodando em CPU sobre 160 seções de documentação escritas a partir do código, e consultas somente leitura ao banco de mercado, com o próprio PostgreSQL como barreira de segurança. A busca foi medida pergunta a pergunta até acertar 29 de 29. Na demo pública, um Gemini gratuito escolhe as ferramentas e um painel mostra cada chamada ao vivo — e documentar o código revelou cinco bugs do InvestLink, corrigidos com teste.
